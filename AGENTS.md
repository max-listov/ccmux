# Project instructions

**Read `CLAUDE.md` in this repository root before making any change.** It is the single source of
truth for working here — repository conventions, what must never be published, the order in which
work is finished, committed and released, and the runtime rules (Bun, never Node/npm).

This file exists only so that agents looking for `AGENTS.md` are pointed at that one file. It
deliberately carries no rules of its own. A second copy drifts: the one that used to live here had
fallen six weeks behind and still taught the runtime conventions while silently missing the rule
that **this repository is public** and must never contain private hostnames, machine labels or
session names — exactly the rule whose absence is most expensive.
