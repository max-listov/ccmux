# fleet --json не отдаёт контекстное окно сессии

## Зачем

`ccmux list --json` сообщает по каждой сессии заполнение контекстного окна:

```json
{"name":"main","agent":"claude","model":"Opus 5",
 "context":{"text":"300k/1.0M 30%","usedTokens":300000,"limitTokens":1000000,"percent":30}}
```

`ccmux fleet --json` для той же сессии этого поля не содержит вовсе:

```json
{"name":"main","agent":"claude","state":"idle","model":"Opus 5",
 "running":true,"uptime":{"text":"12h25m"},"stale":["rules"],"dir":"...","role":null,
 "turnStartedAt":null}
```

Потребитель, который наблюдает сессии всего флота, обязан ходить именно через `fleet`
(один вызов на все машины); `list` отвечает только про локальную. Из-за этого заполнение
контекста — величина, которую ccmux уже знает и уже показывает, — недоступна там, где о
сессии рассказывают удалённо: индикатор приходится либо прятать, либо подменять догадкой.

Два среза одной и той же сущности расходятся по составу полей, и это расхождение не объявлено:
`fleet` выглядит как надмножество `list` по машинам, но оказывается подмножеством по полям.

## Результат

- В `fleet --json` у сессии присутствует то же поле `context` (той же формы, что в `list --json`),
  либо `null`, когда источник его не сообщил.
- Отсутствие замера остаётся отличимым от нуля: `null` — «не знаем», а не «контекст пуст».
- Состав полей сессии в `fleet` и `list` совпадает или расхождение объявлено в документации
  протокола явно.

## План

- [ ] Найти место, где строится сессия для `fleet --json`, и сверить состав полей с `list --json`.
- [ ] Добавить `context` в фолетовый срез, сохранив `null` как «источник не сообщил».
- [ ] Тест: сессия с известным контекстом отдаёт его обоими срезами одинаково; сессия без замера — `null` в обоих.
- [ ] Прописать в документации протокола, чем составы полей срезов различаются (если различаются).

## Acceptance

- [ ] `ccmux fleet --json` содержит `context` у сессии, у которой его показывает `ccmux list --json`, с теми же числами.
- [ ] Сессия без замера даёт `null`, а не нулевые значения.
