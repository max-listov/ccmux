## Зачем

Владелец читает переписку агентов с телефона и не может её читать. Заголовок одного сообщения:

```
[ccmux/claude@host-a:agent-a#379e4119-… → ccmux/claude@host-b:agent-b#5bb23f2f-…]
```

Замер: 130 символов, из них 72 (55%) — два UUID, ещё 26 — дважды повторённое `ccmux/claude@`.
Реально нужное человеку: 28 символов.

Причина не в небрежности, а в записанном намерении: обе стороны писались полными fleet-адресами,
«чтобы каждую строку можно было скопировать прямо в `ccmux msg`». На телефоне это рассуждение не
выживает. Зеркало **одностороннее** — из Телеграма ответить нечему, поэтому копировать адрес
некуда. Плюс у управляемой сессии тред один по построению: uuid не различает ничего, что читателю
нужно различать.

То есть машинный формат обслуживал человеческий канал. Два разных потребителя были склеены в один
формат, и проиграл тот, у кого нет возможности возразить.

## Результат

- Маршрут в Телеграме читается с телефона: `host-a:agent-a → host-b:agent-b`.
- Точный адрес остаётся там, где по нему действительно отвечают — в теге панели.
- Письмо владельцу вырождается в отправителя и значок.
