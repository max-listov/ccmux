# Колонка RESTART требует рестарта, который ничего не изменит

## Что видно

Сразу после раскатки 0.10.1 (релиз тронул ровно два файла, оба на стороне демона) весь
флот — 22 сессии из 23 — помечен `⟳ code`, то есть «перезапусти меня».

Перезапуск не изменил бы **ничего**. Проверено прямым сравнением: для сессий, поднятых
на 0.10.0, сегодняшний `computeStamp` даёт **тот же самый хэш**, что записан при запуске:

```
main   stored b38174d13366c1aa -> now b38174d13366c1aa  SAME recipe
kks    stored fd28498a721eb961 -> now fd28498a721eb961  SAME recipe
base   stored c8033267dfb2ee44 -> now c8033267dfb2ee44  SAME recipe
```

## Корень

`staleReasons` сравнивает номер версии отдельным пунктом:

```ts
if (stamp.version !== now.version) out.push("code");
```

И это ровно то, от чего предостерегает комментарий двумя абзацами выше в том же файле:

> Вопрос намеренно НЕ «версия ли старее». Это мерило врёт в обе стороны: релиз, не
> тронувший промпт, пометит все сессии зря.

Написано верно, реализовано наоборот.

## Почему версия не нужна вовсе

Всё, что запуск вшивает в сессию, уже попадает в хэш, потому что хэш берётся с **самого
argv**, которым сессия и порождается:

| что вшивается | где | в хэше? |
|---|---|---|
| системный промпт (чат-блок, модули, свой адрес) | `--append-system-prompt` | да |
| хуки + statusLine | `--settings` — JSON **строкой в argv**, не путём к файлу | да |
| permission-режим, флаги, extraFlags | argv | да |
| chatEnabled / promptModules / режим | отдельные поля штампа | да |

А то, что версия могла бы поймать сверх этого, она не ловит: хуки зовутся как
`ccmux stop-hook` и резолвят бинарь **в момент вызова** — работающая сессия подхватывает
новый код без перезапуска. `launchEnv` наследует окружение процесса и не содержит ничего
релиз-зависимого.

Итого номер версии не добавляет ни одного истинного срабатывания — только ложные.

## Цена

Колонка задумана как «прочитал — и знаешь, что делать». Ложное срабатывание на весь флот
хуже отсутствия колонки: после пары таких релизов её перестают читать, и настоящее
`chat`/`mode`/`config` утонет вместе с шумом.

## Что делаем

`staleReasons` сообщает только то, что рестарт **реально изменит**. Поле `version` в штампе
остаётся — оно полезно как диагностика («на чём эта сессия поднималась»), но перестаёт быть
поводом для рестарта.
