## Зачем

Когда на сервере пропал бандл, очевидным лечением был штатный установщик — одна строка,
всё уже написано. Но запускать его на рабочей машине оказалось нельзя, и это неправильно:
инструмент установки обязан быть и инструментом починки.

Опасен не сам факт перезаписи. Перерисовать boot-unit тем же содержимым безвредно. Опасно
то, что `--rc-prefix` — аргумент **со значением по умолчанию**: на машине, у которой
идентичность давно есть в `machine.json`, установщик способен объявить её заново. Меняется
rc-prefix — меняются имена в Remote Control, и сессии теряют преемственность.

Из-за одного этого свойства весь установщик пришлось признать небезопасным, и починка
делалась руками. Свойство, которого не хватает, — не «ум», а **сходимость**: описать нужное
состояние и подтянуть только то, что отличается.

## Результат

- Установщик безопасно запускается на любой машине в любом состоянии.
- На здоровой машине он ничего не меняет и ничего не перезапускает.
- На повреждённой — возвращает недостающее и говорит, что именно вернул.
- Идентичность машины он читает, а не назначает.

- [x] Каждый шаг сходящийся: файл пишется, только если отличается от нужного.
- [x] Демон трогается, только если что-то действительно изменилось.
- [x] Итоговый отчёт: что восстановлено, что оставлено нетронутым.

- [x] Запуск без аргументов на машине с конфигом сохраняет её rc-prefix.
- [x] Запуск на машине с удалённым бандлом полностью её восстанавливает.
