# Контекст

Карта флота направленная: ноутбук знает оба сервера, серверы знают друг друга, ноутбук не знает
никто. Дописать его в карту нельзя — это не пробел, а граница безопасности плюс отсутствие адреса.

Решение вынесено в отдельную библиотеку `stitchwire` (репозиторий `~/projects/stitchwire`):
каждая нода дозванивается **наружу** до брокера и держит связь, брокер маршрутизирует вызовы. ccmux
получает второй транспорт, не получая ни одной новой зависимости — он ходит в локальный агент через
Unix-сокет обычным `fetch`.

## Зачем

Агент на сервере должен уметь ответить тому, кто его позвал, и попросить что-то у мака. Сейчас он
доводит работу до конца и не может отдать результат.

## Результат

- `ccmux msg host-C:<сессия>` работает с любого сервера.
- `ccmux fleet` и `ccmux doctor` видят машину без ssh-адреса.
- Транспорт выбирается по направлению, одной строкой в `machine.json`.
- Барьер допуска не ослаблен: приём чата по-прежнему требует доказанного транспорта.

## Что сделано

**Транспорт**

- [x] `src/fleet/wire.ts` — POST в `~/.local/state/stitchwire/agent.sock`, лениво и без зависимостей.
      Отказ (`denied`/`offline`/`timeout`) помечается как транспортный сбой с настоящей причиной, а
      не как ненулевой код команды.
- [x] `RemoteResult.failureDetail` — ssh не умеет отличить «нет маршрута» от «нет agent forwarding»
      и оставляет поле пустым; провод умеет, и общая фраза про ssh для отказа по политике была бы
      ложью.
- [x] `peersOf` объединяет ssh-карту и `wire.peers`; провод выигрывает там, где заданы оба.

**Поверхность**

- [x] `ccmux fleet` показывает `host-C via wire` и его сессии.
- [x] `ccmux doctor` проверяет, что нода реально та, за кого себя выдаёт, и отдельно — что локальный
      агент запущен: без него все wire-пиры читались бы как «недостижимы», и читатель искал бы
      неисправность не на той машине.

**Допуск**

- [x] `remoteTransportAncestor()` вместо `hasSshdAncestor()`: возвращает, какой транспорт найден.
      На Linux — второй дешёвый файл, и только когда ответ ещё не решён по `comm`.
- [x] `parsePsLine` — на macOS `comm` и `args` берутся одним вызовом `ps`, чтобы не удвоить цену,
      ради которой эта функция и написана.
- [x] `isStitchwireAgent` требует и бинарь, и глагол `agent`. `stitchwire call` допуска не даёт.
